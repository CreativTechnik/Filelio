Filelio 1.0.0
Autor: CreativTechnik

SYSTEMVORAUSSETZUNGEN
- macOS 13 oder neuer
- Apple Silicon oder Intel-Mac

INSTALLATION
1. Öffne Filelio-1.0.0.dmg.
2. Ziehe „Filelio.app“ auf „Programme“.
3. Starte Filelio und bestätige die gewünschten Ordner im macOS-Auswahldialog.
4. Aktiviere optional „Filelio Finder“ unter Systemeinstellungen > Allgemein >
   Anmeldeobjekte & Erweiterungen > Finder.

SICHERHEIT
- macOS App Sandbox
- Zugriff nur auf ausdrücklich ausgewählte Ordner
- keine automatische Löschung
- lokale Verarbeitung ohne Dateiübertragung
- temporäre und unvollständige Cloud-Dateien werden übersprungen

APPLE-SIGNATUR
Diese lokale Ausgabe ist ad-hoc signiert, aber nicht mit einer Apple Developer ID
signiert oder notarisiert. Gatekeeper kann beim ersten Start eine Freigabe unter
„Systemeinstellungen > Datenschutz & Sicherheit“ verlangen.
